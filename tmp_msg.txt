Add gathering job, node level and per-node map resolution

Nodes now carry the job that gathers them and the node level, and resolve
the correct map sheet. Zone, node and map are kept as separate fields
because they are different things: a zone can sit inside a named area
(East Yyasulani inside Heritage Found), and it is Heritage Found that
supplies the map used for coordinates.

GatheringPointBase.GatheringType does not line up with the nouns in
GatheringPointName.csv, so the job is mapped explicitly rather than read
off the noun table. Values were verified by sampling the items on each
type and cross-checked against known nodes: 0 = Mining (Iron Ore),
2 = Logging (Maple/Cedar Log, Claro Walnut Log at Lv.100 mature tree),
3 = Harvesting (Laurel at Lv.35 lush vegetation).

Map resolution previously kept only the last Map.csv row per territory,
which silently picked one of several sheets (204 of 614 territories span
more than one). The sheet is now chosen per node by matching the node's
PlaceName against the candidates, falling back to a single-sheet
territory and then to the first candidate.

Bot replies now name the job and level, e.g.
"Broken Water (Lv. 35 harvesting node) - X: ..., Y: ...".
